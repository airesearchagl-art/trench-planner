# JSON形式 v2

トップレベルに `format: "trench-planner"` と `version: 2` を持つ。v1は読込時にv2へ移行し、4寸法の鍵を固定、逆算モードを入力値の検証に初期化する。未知の版は拒否する。

## 保存する内容

- 検討名、GT数、断面条件、ルート色、区間名・距離・勾配。
- `locks`：天端下がり・グレーチング厚・最小下面クリアランス・底部仕上げの編集保護。
- `solver`：検証 / スラブ下げ / 区間勾配 / 区間距離の逆算モード、対象ルートID・区間ID。
- `drawing`（任意）：図面名・ページ番号・ラスター画像の幅と高さ・埋込みJPEG/PNG・校正2点と実距離m。
- `routes[].segments[].trace`（任意）：図面の画像座標pxで表した折れ線。計測値は読込時に座標と校正から再計算する。

計算結果を正本として保存せず、入力から再算定する。寸法mm・距離m・勾配1/nの分母を使用。作図中の未確定点、倍率、図示ルート、現在/必要下げの表示選択は保存しない。

## 図面を含む復元

図面はユーザーが選んだ1ページを最大2400pxに画像化して埋め込む。元の複数ページPDFそのものは保存しない。別ページを選ぶ場合は元PDFを再選択する。選択ページ・縮尺・確定済みの折れ線は他環境でも復元可能。

JSON上限12,000,000バイト、画像URL文字列8,000,000文字、ルート20本・各30区間・1区間500点まで。ブラウザ内の自動保存には容量上限があり、失敗時はJSON保存を案内する。JSONにはユーザーの図面画像を含むので、共有時はそのファイルの内容を確認する。

外部URL・SVG画像・未知モード・不正数値・ID重複・範囲外座標・ゼロ長校正線を拒否する。ブラウザでのJSON読込時には画像の復号と寸法一致も確認する。失敗した読込で現在の条件を上書きしない。名前は表示データとして扱い、HTMLとして実行しない。

スライド作成プロンプトでは画像のbase64本文を省き、図面SVGとJSONの添付を案内する。そのJSON抜粋は再読込用ではない。
