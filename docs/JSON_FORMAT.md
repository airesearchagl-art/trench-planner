# JSON形式 v1

トップレベルに `format: "trench-planner"` と `version: 1` を持つ。検討名、GT数、断面条件、ルート色、区間名・距離・勾配を保存する。

- 入力条件だけを保存し、計算結果は読み込み後に再計算する。
- 図示ルート・表示断面の選択・逆算欄の試算値は画面操作状態であり、JSONには含めない。
- 文字列は表示データとして扱い、HTMLとして実行しない。
- 不正な形式・版・数値・重複IDは拒否し、現在の入力を保持する。
- 寸法はmm、距離はm、勾配は1/nの分母で保存する。
- 元資料などのファイル、画像、認証情報は含めない。
- ファイルは512,000バイトまで、ルート20本まで、各ルート30区間まで。

将来の形式変更ではversionを上げ、v1からの移行を実装する。未知の版を推測で変換しない。
