# M1：寸法の鍵・逆算・図面計測

## 断面から条件を変える

1. 調理室または下膳室の検討例を読み込む。
2. 断面図内の20・35・50・22mmは最初は固定。数値右の鍵を押すと編集できる。
3. 数値を変えるとD最大・最小・許容落差・必要下げと図形の高さが連動する。
4. Sの鍵、または左の「固定する条件と求める値」で逆算を選ぶ。
5. 「勾配」「距離」を求める場合はルートと区間を選ぶ。他区間は変更しない。

スラブ下げの自動算定は、元のSからの増分ではなく、全ルートを満たす最小の刻み値をSへ反映する。製品寸法の鍵は編集保護、Sの鍵は固定値/自動算定の切替。

## PDF・画像から距離を測る

1. 「PDF・画像を読込」でPDF/PNG/JPEGを選ぶ。PDFは読み込んだ後にページ指定可能。
2. 「縮尺の2点を指定」で、図面上の既知寸法の両端をクリック。実距離をmで入力して確定。
3. 作図ルートと区間を選び、「折れ線を描く」で水上から排水先へ順にクリック。
4. 「距離に反映」で区間距離と計算結果へ反映する。区間ごとに勾配を変えられる。
5. 次のルート・区間を選んで繰り返す。倍率を変えても計測距離は維持する。
6. JSON保存で選択ページ画像・校正・確定済み折れ線まで保存する。
7. 「図面＋計算結果SVG」または「印刷 / PDF保存」で計算結果と図面を出力する。

作図中の線は検証結果へ未反映で、出力には確定した線だけ含める。図面計測した区間の距離を数値入力・逆算へ戻すには「手入力に戻す」を選ぶ。

## 検証結果

- 既存9案の必要下げ300 / 450 / 350 / 550 / 300 / 400 / 650 / 300 / 300mmを維持。
- 下膳室S300・1/50の最大延長8.65m。施工余裕10mmなら8.15m。
- 調理室当初③：下処理9.2m、調理室11.4m・1/100を固定すると、下処理の整数分母は156。
- 製品寸法変更・鍵の状態・逆算対象の保存と復元を確認。
- PDF2ページの切替、PNG折れ線、拡大後の校正、再校正による距離の更新を確認。
- 不正JSON・破損PDFの読込では直前の入力を維持。
- 数値入力後のボタン1クリックとTab移動を確認。

`npm run check`：計算・検証22件、型確認、ビルドPASS。`npm run test:e2e`：10件PASS（Windows Edge）。外部ネットワークへ図面を送信する実装はない。

## 現在の範囲

1検討案・1ページの図面。画像化の最大辺2400px、元ファイル30MB、JSON12MB。複数案管理、全ルートを個別ページに出す機能、CAD読込は後続段階。ブラウザ自動保存の容量を超えた場合はJSON保存で引き継ぐ。

自動確認用の図面は合成テストデータ。実際の設計図面での校正精度・操作性は利用者のレビュー対象。
