# 計算契約 v2

## 単位・基準

- 高さ：mm。区間距離：m → 計算時1000倍。
- FL±0から下方向を正とする。
- グレーチング天端は一定。区間の順は水上側からGT等の排水先へ。
- GT数は計画情報。数を変えても経路長を自動短縮しない。
- 全ルートは独立した最遠部→排水先経路。同一部材の共有や合流条件は計算しない。

| 記号 | 初期値 | 意味 |
|---|---:|---|
| S | 300 | 現状スラブ下げ |
| A | 20 | FLからグレーチング天端まで |
| B | 35 | グレーチング厚 |
| C | 10 | 下面からD基準までの下がり |
| E | 22 | スラブ天端から側溝底仕上げまで |
| K | 50 | 水上側で必要な下面クリアランス |
| R | 0 | 追加で確保する施工余裕 |
| ΔS | 50 | 採用下げの切上げ刻み |

```
Dmax = S − A − B − C − E
Dmin = K − C
許容落差 = Dmax − Dmin = S − A − B − E − K
使用可能落差 = 許容落差 − R
H = Σ(L_m × 1000 ÷ n)
必要下げ計算値 = A + B + E + K + R + H
必要下げ刻み値 = ceil(必要下げ計算値 / ΔS) × ΔS
採用下げ = max(現状S, 必要下げ刻み値)
共通採用下げ = max(各ルートの採用下げ)
水上D = Dmax − H
水上下面クリアランス = 水上D + C
残余落差 = 使用可能落差 − H
```

D基準差Cは落差式で相殺される。Cを製品厚などの実寸法と混同して二重控除しない。CがKより大きいとDminは負になるが、基準線より上にあることを表し、クリアランス自体が負になるわけではない。

## 逆算

```
全区間一律とした最大勾配 = 使用可能落差 / 総延長_mm
その1/n表記の分母 = 総延長_mm / 使用可能落差
指定1/nでの最大延長_m = 使用可能落差 × n / 1000
他区間固定時の使用可能落差 = 使用可能落差 − 他区間のH合計
```

落差が0以下の場合、正の勾配は確保できない。負の予算から負の勾配を算出しない。概数の分母は目安であり、採用勾配を再入力して判定する。整数分母を提案する場合は分母を切り上げ、急な側へ丸めない。

## 判定

残余≧0で高さ条件成立。浮動小数の境界だけ1e-8mm以内を同一と扱う。施工余裕の代用ではない。残余10mm未満を注意表示する閾値はアプリ上の注意喚起であり、規格・法令の要求ではない。

## M1の固定条件と自動算定

製品4寸法の鍵は編集保護であり、その寸法を未知数として自動算定するものではない。自動算定の対象は一度に1つ選ぶ。

- 入力値の検証：従来通りS・距離・勾配を保持して必要下げと比較する。
- スラブ下げ：距離と勾配を固定し、全ルートの最大必要下げを刻みで切上げてSに反映する。元のSを下限にしないため、浅くなる場合もある。
- 勾配：S・対象区間の距離・他区間の落差を固定し、残り落差から対象区間の分母を逆算。整数分母の緩い側へ切り上げる。
- 距離：S・対象区間の勾配・他区間の落差を固定し、残り落差から最大距離を求める。1mm未満を切り捨てる。
- 残り落差が0以下では自動逆算を停止。図面計測中の区間距離は逆算で上書きしない。

## 図面計測

校正倍率（m/px）＝既知の実距離m / 校正2点の画像座標距離px。
区間距離m＝折れ線各辺のユークリッド距離pxの合計 × 校正倍率。

表示倍率・画面サイズを変えても画像座標へ逆変換して計測する。各区間は水上から排水先へ作図し、混合勾配では勾配が変わる場所で区間を分ける。図面の差替え・ページ変更で座標と校正を解除し、直前の計測値を手入力距離として残す。

画像上の2点校正なので、スキャン歪み・非等方な伸縮・視差補正は行わない。中心線に沿う実経路を作図する。SVGやPDFの画像化によるクリック誤差を避けるため拡大表示と長い基準寸法を使い、施工余裕は別途入力する。
