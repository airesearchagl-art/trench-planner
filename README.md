# 側溝プランナー / Trench Planner

厨房側溝の区間別勾配と必要スラブ下げを検討する、ブラウザ内で動く設計補助ツールです。Vite + TypeScriptによる静的サイトとしてGitHubからVercelへ配信します。

## 現在の機能

- スラブ下げ・製品寸法・最小クリアランス・施工余裕を変更
- 複数ルートと区間ごとの距離・勾配、ルート色の設定
- 使用可能落差、必要下げ、クリティカルルート、水上クリアランスの判定
- 最大一律勾配、指定勾配での最大延長、他区間固定時の勾配の逆算
- 寸法付き横断図と縦断図（現在の下げ／必要下げを反映）の表示
- バージョン付きJSON保存・読込、ブラウザ内の自動保存
- SVG図、スライド作成用プロンプトのダウンロード
- ブラウザの印刷画面からPDF保存（現在の案と図示ルート）

PowerPointは本ツール内で生成しません。プロンプト・JSON・SVGを対応する資料作成環境へ渡して作成します。現版は1案ずつの検討用です。複数案の横並び比較・一括資料出力は後続フェーズです。

## 起動

Node.js 24を推奨します。

```sh
npm ci
npm run dev
```

```sh
npm run check
npm run test:e2e
npm run build
```

Windowsのブラウザ検証はインストール済みEdgeを使用します。CIではPlaywright Chromiumをインストールして使います。

## 計算範囲

初期値はスラブ下げ300、天端下がり20、厚35、D基準差10、底部仕上げ22、最小下面クリアランス50、下げ刻み50、施工余裕0（全てmm）。使用可能落差は173mmです。

高さ条件だけを計算します。流量・流速・排水能力、必要な衛生勾配、GT本体の埋込深さ、接続口、合流段差、構造耐力は検証しません。勾配は側溝底の縦断勾配で、グレーチング天端は一定とします。ルート長は接続先GTまでの実経路長です。

入力データはブラウザ内に留まり、JSONを明示的に出力して持ち運べます。ブラウザデータの削除や公開先URLの変更で自動保存は引き継がれません。
